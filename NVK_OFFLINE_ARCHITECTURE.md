# NVK OS — Offline & Sovereign Architecture (OMEGA 2.1)

## Sovereign Operation

NVK OS is designed to support local-first operation:
- **Local Deterministic Kernels**: Arithmetic, document generation, and workspace creation run entirely client-side.
- **Client-Side Artifacts**: Generated files and code projects are stored in local artifact registries.
- **Zero Cloud Mandate**: Core OS navigation, command execution, and verification do not depend on cloud-hosted language model APIs.
